# ChurnIQ — Customer Retention Decision System

An end-to-end Data Science portfolio project covering data quality, SQL analytics, EDA, classical ML, probability calibration, threshold selection, customer risk scoring, and a retention-campaign scenario calculator.

**Starter dataset:** IBM Telco Customer Churn. This supports ordinary churn classification, not causal uplift estimation. Do not claim that churn risk predicts which customer will respond to an offer.

> This is a starter codebase, not a validated production system. Run the experiment locally and report only metrics generated by your own run.

## Quick start (Windows PowerShell)

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
python scripts/download_dataset.py
python -m churniq.cli all --data data/raw/Telco-Customer-Churn.csv --out artifacts
streamlit run app/streamlit_app.py
pytest
```

If the download URL changes, obtain the CSV from the IBM Telco Customer Churn repository and save it to `data/raw/Telco-Customer-Churn.csv`.

## Features
- Data quality checks and feature/target separation
- SQL analytics using SQLite
- EDA plots and segment summaries
- Logistic regression and random forest baselines
- PR-AUC, ROC-AUC, precision, recall, F1, Brier score, calibration, confusion matrix and lift by risk decile
- Threshold selection on validation data, with a held-out test set
- Permutation feature importance
- Customer-level risk scores and illustrative campaign economics
- Streamlit dashboard and automated tests

## Modeling protocol
1. Target is `Churn = Yes`; `customerID` is excluded from predictors.
2. `TotalCharges` is coerced to numeric; blanks become missing values.
3. Stratified train/validation/test split.
4. Preprocessing is fitted within each training pipeline.
5. Select the operating threshold using validation data and F2.
6. Select the model using validation PR-AUC; evaluate once on held-out test data.
7. Risk scores for all rows are a portfolio demo; scores on training rows are in-sample and must not be presented as unbiased predictions.

## Business calculator caveat
The campaign calculator combines churn risk with assumed offer success, customer value and offer cost. It is a scenario tool, **not causal uplift modeling**. Estimating incremental campaign impact requires suitable treatment/control data and causal assumptions.

## Limitations
- The dataset is a common teaching benchmark and not a time-aware longitudinal evaluation set.
- Churn risk and feature importance are not causal explanations.
- Thresholds should reflect real business costs, not accuracy alone.
- Review source terms before redistributing the dataset.
- No benchmark metrics are claimed in this README.
